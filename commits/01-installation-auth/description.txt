Commit message:
Fix Freebuff installation authentication loop

Description:
Freebuff login tokens are issued by the Freebuff authentication flow and are
not valid on Codebuff's /api/v1/me validation endpoint. Skip that incompatible
check in Freebuff mode so an installed Freebuff binary starts with a valid
Freebuff login instead of repeatedly asking the user to log in.
